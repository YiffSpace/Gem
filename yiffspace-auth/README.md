# YiffSpace::Auth

Logto-based auth engine for https://yiff.space and related projects. Lives
alongside, and depends on, the [`yiffspace`](../yiffspace) gem in this repo.

## Installation

Add this line to your application's Gemfile:

```ruby
gem "yiffspace-auth"
```

And then execute:

```bash
$ bundle install
```
